Latest Projects

Two Million Hack the Box Machine

This machine focused on web application enumeration, reversing obfuscated JavaScript to gain initial access, exploiting an exposed API to obtain admin privileges, leveraging command injection for remote code execution, extracting credentials for SSH access, and performing Linux privilege escalation to achieve root access.

Cap Hack the Box Machine

This machine focused on web enumeration, analyzing a PCAP file in Wireshark to recover SSH credentials, and gaining initial access through SSH. After enumerating the system with LinPEAS, I identified a misconfigured Python capability and exploited it to escalate privileges and obtain root access.

Simple CTF Try Hack Me

This machine involved web enumeration, directory discovery with Gobuster, identifying and exploiting CVE-2019-9053 in CMS Made Simple to obtain SSH credentials, and gaining initial access. After logging in via SSH, I enumerated sudo privileges and exploited a misconfigured sudo Vim permission to escalate privileges and obtain root access.
